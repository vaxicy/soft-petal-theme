# Soft Petal Theme

A gentle and elegant Chrome theme inspired by flower petals, warm paper texture, and a calm minimalist workspace.

Soft Petal 是一款灵感源自花瓣、温润纸张质感与静谧极简工作空间的 Chrome 主题，柔和、干净、优雅。

## Overview

Soft Petal wraps your browser in a soft pastel petal palette — a quiet, premium feeling for everyday browsing, like opening Chrome inside a calm room with soft flower petals and warm natural light. No images, no wallpapers, no gradients — only carefully balanced UI colors for a clean, comfortable experience.

Soft Petal 以柔和的粉彩花瓣配色包裹你的浏览器，营造安静而精致的日常浏览氛围——如置身洒满温暖自然光的静谧房间，周围是柔软的花瓣。无图片、无壁纸、无渐变，仅以精心调配的界面色彩呈现干净、舒适的视觉体验。

## Design Concept

The theme is built on a soft petal palette:

- **Toolbar** — `#F9F5F6` warm cream white
- **Frame** — `#F8E8EE` soft blush pink
- **Active Tab** — `#FDCEDF` light petal pink
- **Accent** — `#F2BED1` gentle petal pink
- **Text** — `#6B5860` soft muted brown

It deliberately avoids childish pink, overly cute styling, and bright saturated colors — the result stays calm, elegant, and easy on the eyes.

## Features

- Pure color theme — no wallpaper, no background images, no gradients.
- Soft contrast with readable text for comfortable daily use.
- Minimal and elegant pastel aesthetic.
- Carefully tuned tints for buttons, frame, and background tabs.

## Installation

### From Chrome Web Store

1. Open the Soft Petal Theme page on the Chrome Web Store.
2. Click **Add to Chrome**.

### Load unpacked (local)

1. Download or clone this repository.
2. Open `chrome://extensions` in Chrome.
3. Enable **Developer mode** (top-right).
4. Click **Load unpacked** and select this folder.
